# Setup do Ambiente — Hackathon IA

Este repositório contém os tutoriais de instalação e configuração do ambiente de desenvolvimento utilizado no Hackathon de Inteligência Artificial.

## Objetivo

Padronizar o ambiente dos participantes para facilitar as práticas com Cursor, Git, GitHub, Node.js, Python, Jupyter Lab e MCPs.

## Tutoriais disponíveis

### Windows

Arquivo: `Setup de Instalação no Windows.pdf`

Inclui instalação e configuração de:

- Cursor
- Git
- GitHub
- Node.js
- Python
- Jupyter Lab
- MCPs

### Linux

Arquivo: `Setup de Instalação no Linux.pdf`

Inclui instalação e configuração de:

- Cursor
- Git
- Node.js
- Python
- Jupyter Lab
- MCPs

## Ferramentas utilizadas

| Ferramenta | Finalidade |
|---|---|
| Cursor | IDE com IA integrada |
| Git | Controle de versão |
| GitHub | Hospedagem de repositórios |
| Node.js | Ambiente JavaScript |
| Python | Desenvolvimento e IA |
| Jupyter Lab | Notebooks interativos |
| MCPs | Integração de ferramentas com IA |

## Requisitos recomendados

### Windows

- Windows 10 ou superior
- 8 GB de RAM ou mais
- Permissão para instalar programas

### Linux

- Ubuntu ou Debian
- Python 3
- Node.js
- npm

## Links oficiais

- Cursor: https://cursor.com
- Git: https://git-scm.com
- GitHub: https://github.com
- Node.js: https://nodejs.org
- Python: https://python.org

## Observações importantes

- Use preferencialmente o e-mail institucional.
- Não compartilhe tokens de autenticação do GitHub.
- Os MCPs precisam ser ativados manualmente dentro do Cursor.
- Após configurar os MCPs, reinicie o Cursor.
